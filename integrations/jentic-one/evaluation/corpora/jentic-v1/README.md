# Jentic security corpus v1

This corpus evaluates the two surfaces protected by the Jentic One plugin: eligible upstream
response text and agent-visible OpenAPI metadata. It is intentionally stored outside the
general Barrikade training dataset and is never consumed by a training command.

`reviewed.jsonl` is the approved, family-stratified release corpus. Small synthetic corpus
fixtures belong under tests and are generated by the test suite rather than stored here.

## Split and leakage rules

- A `family` may occur in only one split, preventing paraphrases from crossing boundaries.
- Normalized duplicate text is rejected.
- The release test split must never be supplied to student or teacher fine-tuning.
- Production-derived examples must be redacted before entering this repository and tagged
  `redacted_production`.
- The validator rejects common credential and private-key shapes. Do not include headers,
  cookies, credentials, actor emails, customer identifiers, or unredacted production text.
- Model reports contain case IDs and hashes only, never corpus text.

## Release gates

The release gates require at least 95% attack recall per surface, no missed critical cases, at
most 0.3% benign blocks, and at most 1% benign flags.

Validate locally with:

```shell
python integrations/jentic-one/scripts/evaluation/validate_jentic_corpus.py
```

CI uses `--require-reviewed` for release-candidate validation.

## Discovered draft review pool

The pinned source manifest and builder in `integrations/jentic-one/evaluation/sources/` now produce a larger candidate
pool under ignored `build/jentic-corpus-sources/`. The verified build on 2026-08-11 contains:

| Surface and label | Draft candidates |
|---|---:|
| Runtime response, benign | 1,200 |
| Runtime response, prompt injection | 1,176 |
| Specification metadata, benign | 2,000 |
| Specification metadata, prompt injection | 1,176 |

The project owner approved all 5,552 candidates on 2026-08-11. The freeze process reserves
exactly 1,000 cases from each surface/label pair as the independent test partition (4,000 total)
and uses the 1,552 surplus cases for calibration-only validation. No reviewed row is assigned to
training. Runtime/specification variants of the same attack remain in one family and one split.

`reviewed.jsonl` is the frozen corpus. `reviewed.manifest.json` records the approval, source and
corpus digests, attribution, split policy, and the zero-overlap check against the earlier 13,480-row
student dataset. Test results must not be inspected until a candidate meets every validation gate.
